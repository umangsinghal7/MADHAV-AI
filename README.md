# 🤖 MADHAV-AI

MADHAV-AI is an AI-powered web application designed to provide intelligent responses and assist users through smart interaction.  
This project demonstrates how Artificial Intelligence can be integrated into modern web applications using a full-stack JavaScript environment.

---

## 🚀 Features

- 🤖 AI-based response system
- 🌐 Clean and user-friendly interface
- ⚡ Fast and lightweight web application
- 📊 Data handling and intelligent processing
- 🔧 Modular and easy-to-expand architecture

---

## 🛠 Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript
- EJS (Embedded JavaScript Templates)

**Backend**
- Node.js
- Express.js

**Other Tools**
- Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/umangsinghal7/MADHAV-AI.git
```

### 2️⃣ Navigate to the project folder

```bash
cd MADHAV-AI
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the application

```bash
node app.js
```

Server will start on:

```
http://localhost:3000
```
